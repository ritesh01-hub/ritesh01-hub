## Projects

### Wanderlust: Full-Stack Property Listing Platform
[Live Demo](https://wanderlust-fjo7.onrender.com) · [Source Code](https://github.com/ritesh01-hub/Wanderlust) · Jan 2026 – Apr 2026

An Airbnb-style platform where users can browse properties, create and manage listings, post reviews and view locations on a map.

- MVC architecture with end-to-end CRUD across 9 RESTful endpoints and 2 Mongoose models, including nested review subdocuments
- Session-based authentication and authorization using Passport.js
- Request validation with Joi and centralized `wrapAsync` error-handling middleware
- Image storage with Cloudinary and geocoding with Mapbox
- API behavior and edge cases tested with Postman; deployed on Render with MongoDB Atlas

**Stack:** Node.js, Express.js, MongoDB, Mongoose, EJS, Passport.js, Joi, Cloudinary, Mapbox, Bootstrap

### Employee Management System: Role-Based Task Dashboard
[Live Demo](https://employee-management-system-three-jet.vercel.app) · [Source Code](https://github.com/ritesh01-hub/employee-management-system) · Nov 2026

A frontend-only task management app where an admin assigns tasks and employees accept, complete or fail them.

- Separate admin and employee dashboards with task statistics and a per-employee overview
- Authentication and task state managed with React Context API and custom hooks (`useAuth`, `useTasks`)
- Data persisted in the browser with localStorage (no backend)
- Deployed on Vercel with continuous deployment from GitHub

**Stack:** React.js, Vite, Tailwind CSS, Context API, localStorage
